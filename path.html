The Pilgrim's Path 巡礼路 The Pilgrim's Path

一歩踏み出すたび、
世界は少しずつ姿を変える。

あなたがここへ辿り着いた理由は、
誰にも分からない。

けれど旅は、
いつも最初の一歩から始まる。

Pilgrim's Record 巡礼者の記録

RAVEN ARCHIVEでは、
巡礼者ごとに旅の記録が残されます。

禁書庫を訪れ、
黒い森を歩き、
修道院で学び、
旅籠酒場で火を囲む。

その足跡は、
あなた自身の巡礼者手帳へ
静かに記録されていきます。

巡礼を始める → 巡礼者の手帳が開かれます
旅は急がなくていい。
